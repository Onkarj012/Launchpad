# Base Resume References

These files are historical references for the resume format and approved content. They are not a rotating three-base system.

## Current tailoring rule

- Keep **Stride** in Experience for every tailored resume as **Founder & Lead Engineer**.
- Select exactly two projects per JD from **Lore Engine, StockXpert, GovBench, and PromptForge**.
- Choose the two projects with the strongest truthful keyword match to the JD, using variety as a tie-breaker.
- Reframe, reorder, shorten, or combine only claims supported by the master resume.

The source of truth is `master_prompt.md`. The ATS master is `resumes/master/Master_Resume_ATS.tex`; tailored sources go in `resumes/sources/`, and verified PDFs go in `resumes/output/`.

The base files and preview PDFs remain available for historical comparison. Do not treat their old project combinations or per-job swap instructions as current policy.
