# Proof packet

This directory plans and audits public proof. It does not claim that a repository, demo, recording, metric, or profile has been checked until a dated audit records the evidence.

## Use

1. Start with `proof-packet.md` to choose the strongest existing proof for a role.
2. Complete `github-audit.md` before calling a repository link application-ready.
3. Complete `demo-and-intro-video.md` before sharing a demo or recording.
4. Record any completed asset with a date, public link, evidence source, and limitations. Keep private material and credentials out of this directory.

The resume still cites only `resumes/master/Master_Resume_ATS.tex`. A proof asset can support outreach or a proof-of-fit note after verification; it does not create resume evidence.
