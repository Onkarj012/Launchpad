# Base Resume References (ARCHIVED — pre-template era, 2026-07)

**Superseded.** These bases predate the single-canonical-template system introduced 2026-07-17.
They are kept only for historical comparison. Do not use them as a starting point for a resume,
and do not treat their old project combinations or per-job swap instructions as current policy.

The current layout source of truth is `resumes/templates/Onkar_Template.tex`. Tailor only inside
its `%== TAILOR-START/END ==` slots. Content/evidence source of truth is
`resumes/master/Master_Resume_ATS.tex`. Tailored sources go in `resumes/sources/<YYYY-MM-DD>/`,
and verified PDFs go in `resumes/output/<YYYY-MM-DD>/`. See the `resume-latex` skill.

## Historical tailoring rule (still true, now enforced by the template)

- Keep **Stride** in Experience for every tailored resume as **Founder & Lead Engineer**.
- Select exactly two projects per JD from **Lore Engine, StockXpert, GovBench, and PromptForge**.
- Choose the two projects with the strongest truthful keyword match to the JD, using variety as a tie-breaker.
- Reframe, reorder, shorten, or combine only claims supported by the master resume.
