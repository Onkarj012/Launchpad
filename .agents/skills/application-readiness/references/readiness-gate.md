# Readiness gate

Required for `ready`:

1. Original company or named ATS requisition URL is captured and live.
2. The original page accepts applications or clearly states the opening is active.
3. Company website/domain and public company presence support the employer identity.
4. Lead and original page agree on company and role; differences in location, work authorization, seniority, pay, or employment type are resolved against the original page.
5. No application fee, training fee, employment bond, anonymous client, or suspicious-domain signal is present.
6. Master hard gates pass using original-page evidence.

Use `verify manually` when a fact cannot be checked. Do not mark it ready. Record: source URL, original ATS URL, checked-at time, job/requisition ID, readiness status, and evidence URLs/notes.
