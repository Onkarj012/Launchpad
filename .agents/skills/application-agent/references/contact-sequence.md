# One-human sequence

For a top application, select one person at a time: engineering recruiter or hiring manager first; CTO/founder for a company of about 50 people or fewer; relevant engineer, alumni, or mutual connection only after the first contact has had the configured silence window.

Before drafting, inspect `conversion/templates/contacts.tsv` copies and the tracker evidence supplied by the user for the same `application_key`. If a sent, pending, or planned contact exists, do not create a parallel first message. State the existing sequence and next eligible date instead.

Draft only on explicit request. The first note names the role, one concrete project-to-responsibility connection, and a low-pressure request to review the application. A later note adds one relevant proof link. Do not guess emails, claim a referral, or send.
