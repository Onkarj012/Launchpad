# Submitted answers

Create a dated Markdown file beside the application record. Copy the portal question verbatim, then record the exact submitted answer only after the user confirms it. Unknown fields stay `Not Verified`; do not infer salary, authorization, experience, or employment facts.

Required fields: expected salary, current CTC, notice period, location preference, remote preference, work authorization, years of experience, resume version/path, and cover note.

## Capgemini / current employment

The agent must ask the user to confirm any portal-specific phrasing before it is marked submitted.
