# Report shape

For each section: JD demand, current evidence, exact provenance locator, gap diagnosis, verdict (`red`, `orange`, `green`, or `blue`), and a truthful rewrite if needed.

Then report the matrix and missing requirements, content/JD/artifact gate results, ATS readiness with limitations, six-second impression, three critical fixes, three quick wins, and a submit/no-submit call. A rewrite may select, shorten, reorder, or reframe approved evidence; it must not strengthen scope, metrics, ownership, or maturity.
