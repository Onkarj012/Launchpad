# Revision menu

Full-stack: JavaScript/TypeScript, React rendering/hooks/state, Next server/client boundaries, REST, auth, SQL/modeling, caching, errors, testing, deployment.

Applied AI: embeddings, chunking, dense/sparse retrieval, reranking, RAG evaluation, hallucination control, tool calling, structured outputs, agents versus workflows, prompt injection, latency/cost, deterministic logic.

General software: arrays, strings, maps, stacks, basic trees/graphs, complexity, API design, background jobs, rate limits, logging, monitoring.

A revision session is complete only after the user can explain a concept, solve or outline one representative problem, and connect one choice to a project or JD where relevant.
