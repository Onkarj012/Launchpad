What the run data says

  1. Supply is the bottleneck, not the gates. Of 3,090 stored jobs, 226 mention Pune. Only 82 come from employer ATS boards, from about eight employers: Barclays, BP, 6sense, Autodesk, Capco, Blue Altair, Delta Capita, Bosch. Every ready role came from two of them.
  2. The board registry is aimed at the wrong place. 255 boards, none marked Pune-relevant. The 123 enterprise Workday tenants are mostly US companies (Boeing, CVS Health, Chevron, Cincinnati Children's). They account for most of the roughly 3,000 "onsite, not Pune" rejects per run.
  3. The company cap now binds. Eight ready roles from two employers become four under the two-per-company rule. More employers is the fix, not a looser cap.
  4. Portal leads stall at verification. About 40 LinkedIn, Glassdoor, Instahyre and Wellfound leads per run have no JD and no employer route. Many come from employers with their own ATS: Mastercard, BMC, Atlas Copco, TransUnion, MetLife, BNY, Jefferies, Accenture, Purplle, Avaloq. Nothing matches a portal lead to that employer's own board.
  5. Several built lanes produce nothing. The career-page crawler has an empty company list. The startup lane is not wired into the daily run. Web discovery returned nothing. Naukri, Foundit, Hirist, Cutshort and Peerlist need live injection or the Apify rescue. Glassdoor returns 403; LinkedIn returned 429 on the third run.
  6. Some Pune roles may be false title rejects. To audit: Barclays "Recon Developer", "Sterling Developer", "Test Engineer", "Data Analyst"; BP "Junior Business Intelligence Specialist"; 6sense "Software Engineer II"; Blue Altair "Analyst / Consultant - Fullstack Developer". Some will be correct rejects. None has been checked yet.

Goal and how we measure it

Target: on 5 of 7 consecutive IST days, at least 10 shortlisted roles from at least 6 employers, every one verified (JD, employer route, live, full-time or paid internship, fresh, Pune-area or India-eligible remote), with at least 2 Strict matches a day.
Fixed guardrails: fail-closed gates, two-per-company cap, no auto-apply, draft-only outreach, v5-only writes, user-owned checkboxes untouched.

Every run reports fetched, Pune or India-eligible, passed gates, ready, scored, shortlisted, employers represented, Strict count, and yield per source per request. Sources that spend requests without producing ready roles get paused.

Workstreams

Ordered by expected yield. A to D improve the current pipeline. E opens new avenues. F to H make the result usable and trustworthy.

A. Build a real Pune and India employer registry biggest lever

  1. Seed 250 to 400 employers in four tiers: Pune GCCs and captives (Mastercard, BNY, UBS, Deutsche Bank, Citi, Allstate, John Deere, Siemens, Bosch, Eaton, Cummins, Honeywell, ZS, Amdocs, NVIDIA, Rapid7, Veritas, Qualys, BMC, TransUnion and more); Pune product companies (Icertis, PubMatic, Druva, Mindtickle, Persistent, Synechron, Zensar, KPIT and more); India AI and dev-tool startups from YC, VC portfolios, Inc42 funding news and Pune incubators; and services firms with graduate programs as a separate tier.
  2. Find each employer's ATS from its careers page: Workday, SuccessFactors, Oracle, iCIMS, Greenhouse, Lever, Ashby, SmartRecruiters, Workable, Recruitee, Darwinbox, Keka, Zoho.
  3. Verify each board with one public request. Tag Pune and India relevance from real job locations.
  4. Register verified boards in config/board-registry.json, the file production reads.
  5. Re-prioritise: Pune boards first every morning; US-only tenants with zero India yield over 7 days rotate out.
Done when: 150+ verified Pune or India boards, each with a probe record, and a bounded run shows Pune roles from 25+ employers.

B. Turn portal leads into employer routes

  1. When a portal lead's company is in the registry, search that employer's own board for the same title. Promote only on employer, title and location match, plus requisition when present.
  2. Use visible external apply links on Instahyre and Wellfound. No login, no private endpoints.
  3. Raise the resolver budget only after measuring verified routes per request.
  4. One LinkedIn pass per run; back off for the day on 429.
Done when: a bounded run converts 10+ portal leads to verified employer routes, with zero wrong matches in a manual check.

C. Turn on the lanes that are built but empty

  1. Structured career pages (LP-009): feed the existing sitemap and JSON-LD crawler with employers that use no supported ATS.
  2. Startup company careers: wire the existing lane into the daily run.
  3. Web discovery: find why Brave and SearXNG returned nothing and fix the cause.
  4. Apify rescue for Naukri, Foundit and Hirist: Onkar-invoked, capped cost per run, leads go through workstream B.
  5. TheirStack: deferred until free-source yield is measured.
Done when: every source ends each run as ok, empty with a reason, or disabled by decision. None stays unavailable by accident.

D. Audit the gates for false rejects, without loosening them

  1. Hand-label 100 random rejects per code (title off-target, seniority, remote scope unclear, location not verified, 3+ years).
  2. Check multi-city listings, Pune suburbs, "Maharashtra" only, and titles like Analyst, Consultant, Associate, Engineer I/II.
  3. Fix only proven false rejects, each with a regression test from the real example.
  4. Explain why every selected role is Backfill and none is Strict, even when posted the day before.
Done when: false-reject rate per code is measured, fixes are tested, and Strict selection is explained or fixed.

F. Make the shortlist usable each morning

  1. Each role gets a one-line "why it fits", shift or location caveats, and the apply link.
  2. A checked row builds a tailored one-page resume PDF on this Mac.
  3. Outreach drafts to the hiring manager or recruiter where one is identifiable. Draft-only.
Done when: going from shortlist to application takes Onkar under 15 minutes per role.

G. Run it every day, unattended, in shadow

  1. Morning and midday runs on the isolated config for 7 days. No Notion writes.
  2. One daily funnel report with source health and per-source yield.
  3. Watch LinkedIn 429, Glassdoor 403, board failures, and scorer variance (the same role scored 72 one run and 67 the next).
Done when: 7 consecutive days of complete reports, with the target met on 5 of them.
