+# Proof of Fit
+
+Create one small, truthful proof artifact for a top application. The aim is a concrete reason to speak with Onkar, not unpaid consulting or a multi-hour assignment.
+
+Read `references/artifacts.md` before choosing the form. Evidence comes from the approved resume/project sources and the supplied JD.
+
+## Steps
+
+1. **Anchor** — extract one important responsibility or product problem from the JD and one matching approved project fact.
+ *Done when:* the JD phrase and evidence source are both explicit.
+
+2. **Choose** — select the smallest useful form: three product observations, a short architecture suggestion, existing feature demo, small mockup, relevant code link, or brief approach note.
+ *Done when:* the form can be completed without new unsupported claims or unpaid project work.
+
+3. **Draft** — write a dated artifact with problem, evidence, one practical proposal/connection, limitation or assumption, and an optional link. Never claim knowledge of internal systems.
+ *Done when:* every factual claim is sourced and every assumption is labeled.
+
+4. **Record** — save the artifact path in the application record and offer it only when the user asks for a message or chooses to share it.
+ *Done when:* the artifact is reusable, reviewable, and not represented as sent.

# Launchpad guardrail vocabulary
Use these exact meanings in every Launchpad skill.
- **user-owned** — `Make Resume` and `Applied?` values belong to Onkar. Skills may read them but must never check, uncheck, or mutate them.
- **draft-only** — outreach output is local or v5 draft state. It is not a Gmail draft and is never sent by a skill.
- **v5-only** — explicitly authorized live writes target only declared Launchpad v5 stores through the scoped gateway. v3/v4 are historical read-only systems and are never fallbacks.
- **fail-closed** — unknown evidence, missing credentials, unresolved original-application URLs, and unverified contacts remain blank or `Not Verified`. Never invent dates, salary, contacts, links, or experience.
- **local-compile** — resume PDFs are built on this Mac. Sources and sidecars stay under `resumes/sources/<date>/`; `resumes/output/<date>/` contains PDFs only.
- **no auto-apply** — no skill submits an application, sends email/DM/referral, automates LinkedIn, or changes a user-owned checkbox.
