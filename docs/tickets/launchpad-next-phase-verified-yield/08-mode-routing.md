# 08: Mode routing

**What to build:** One daily crawl feeds three modes: Pune, Startup and Remote. Each role gets one primary mode and tags for any other mode it fits. Primary mode follows the order Startup, then Pune, then Remote. This order is an assumption and needs confirmation. The two-per-company cap applies within each mode's shortlist. Each mode returns a full verified results list and a shortlist.

**Blocked by:** None (can start immediately)
