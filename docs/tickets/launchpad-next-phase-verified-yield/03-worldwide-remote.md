# 03: Worldwide remote roles pass

**What to build:** Remote roles that say worldwide, anywhere, or global pass when the job description sets no country limit and asks for no foreign work authorization. They carry the label `Remote: worldwide, no country limit`. Roles limited to the US, Canada, EU, UK, or LATAM, or that need foreign work authorization, stay rejected. India and APAC remote roles still pass.
